# Overview

A revision of React training plan which focuses on the latest version of React (19.0.0). It will assist trainees improve module splitting and React rendering.

Author: Hoang Nguyen Van <[hoang.nguyenvan@asnet.com.vn](hoang.nguyenvan@asnet.com.vn)>

## Requirements

- [Node](https://nodejs.org/en/) >=20.0.0 / [npm](https://www.npmjs.com/) >=5.3.0
- [Vite](https://vitejs.dev/) >=5.0.0

## Getting Started

Step by step to run this app in your local

### Redirect to folder

```
cd pokemon
```

### Install packages

At your directory root, run:

```
pnpm install
```

### Run Project

```
pnpm dev
```

Open on web: http://localhost:5173/
